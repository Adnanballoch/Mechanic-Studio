# Mechanic Studio

**Category:** Platform
**Part of:** AutoMatrixLab

AI native browser games where one action carries the learning, then you open the game up and build your own.

## Overview

Mechanic Studio is a games platform I built where every game turns on one action: slice, launch, pop, match, sort or spell, with any subject's questions swapped in. Each game has three doors. Play it. Learn how it was made, slide by slide, where moving a slider changes the real game straight away and the code lines for that setting light up. Then Build your own version: tune the physics, swap the background, pictures and sounds, write your own questions, add rules without code, or change the real code line by line. An AI assistant helps at every step, themes change the whole look, two players can take turns on the same game, and My progress shows how you play over time.

It is for children, parents and teachers, and for adults who want to get into game development or build their STEM skills. Curiosity turns into imagination, and imagination turns into something you made.

## Games

Slice HD, Topple, Pop, Bubble Brain Pop, Money Match 3, STEM Match, Spell Match, Swipe Sort, Physics Quiz.
